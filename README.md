# TechShop Frontend

**TechShop Frontend is an e-commerce simple project application built with React, Vite, and Tailwind CSS. The application supports a product catalog, a global shopping cart, client-side routing, and a responsive user interface.**

## Prerequisites
Node.js 18+

npm or yarn

## Setup
### Step 1: Clone the repository
```bash
git clone https://github.com/fabioc0de/E-Commerce-Frontend-React.git
cd E-Commerce-Frontend-React/techshop-frontend
``` 
### Step 2: Install dependencies
**Install the required packages:**

```bash
npm install
```
### Step 3: Verify the project structure
**Make sure the following key files are present in the `src/` directory:**

```text
src/
├── components/
│   ├── layout/        # Header, Footer, Hero, Layout
│   ├── products/      # ProductCard, CartContext
│   └── ui/            # Brand, NavBar, SearchBar
├── pages/             # Home, Productos, Car, NotFound
├── App.jsx
└── main.jsx
```

### Run the project
**Start the development server:**

```bash
npm run dev
```
